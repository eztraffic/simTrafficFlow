Core Architecture

三大核心系統模組

Simulation Engine

微觀車流模擬器

基於 Three.js 與 Web Worker 的高效能 3D/2D 物理計算引擎，支援真實時間動態車流與多車種模擬。

  • 智慧跟車與變換車道模型
  • 汽機車混合車流、機車兩段式左轉待轉區
  • 行人微觀流動、行穿線衝突避讓
  • 數位孿生 (Digital Twin) 真實時間時鐘同步
進入模擬器 (Simulator)
CAD / GIS Editor

路網編輯器

基於 Konva.js 畫布的 2D CAD 路網編輯環境，支援直覺式繪製與 OpenStreetMap 向量圖資一鍵建構。

  • OpenStreetMap (OSM) 向量圖資匯入自動生成幾何
  • Synchro 模式：極速十字路口建模與車道轉向配置
  • 車道幾何、槽化線標線、標誌與偵測器佈設
  • 多時相號誌計畫時序配置與衝突矩陣編輯
  • 支援 Undo/Redo 歷史操作與一鍵直通 3D 模擬
進入路網編輯器 (Editor)
3D Environment

3D 場景地物編輯器

建置都會建築、路側設施、景觀樹木與施工障礙物，為微觀交通模擬提供生動擬真的 3D 視界。

  • 多樣化都會建築物與高樓模型配置
  • 路側設施、行道樹、路燈與護欄地物
  • 施工交錐與障礙物擺設（模擬車流閃避）
  • 場景 XML 一鍵導出並即時連結模擬器
進入場景編輯器 (3D Scene)

Engineering Innovations

核心技術優勢

結合台灣本土化交通工程設施之車流模擬

智慧跟車與變換車道

基於物理慣性與期望車距模型，精確計算每輛車的加速度、巡航速率、安全煞停距離及盲點變換車道決策。

在地下化汽機車混流模式

專為臺灣及亞洲高機車密度環境設計，完整模擬機車車陣滲透、路口兩段式左轉待轉區停等與專用時相動態。

微觀行人流與衝突避讓

模擬行人於行穿線、對角斜交人行道上的移動速度與集結群聚，並實作人車交織時車輛禮讓機制。

多時相號誌與 AI 最佳化

內建週期、綠信比與相態編輯，並具備迭代號誌優化演算法與警員手動交管接管模式，有效降低平均延滯時間。

OpenStreetMap 圖資整合

支援點選地圖範圍並由 OSM 向量資料庫一鍵匯入真實道路幾何，自動轉換為車道拓樸與節點網路，節省 90% 建模工時。

數位孿生與實時圖表

支援以真實世界時間時鐘同步運行的數位孿生模式。

Getting Started

快速上手與本地端運行

ezTraffic 為純靜態 Web 應用程式，無任何後端依賴，支援直接線上使用或一鍵於本機啟動。

方式一：GitHub Pages 線上直接體驗

直接造訪 GitHub Pages 靜態網站，選擇您想探索的模組或點擊任一範例檔案，立即於瀏覽器中流暢運行，完全免去安裝環境的困擾。

立即體驗微觀模擬器

方式二：於本機啟動靜態伺服器 (Local Server)

因瀏覽器安全限制 (CORS/file://)，建議透過本機簡易 HTTP 伺服器啟動：

# 透過 Python 3 (最簡便) python3 -m http.server 8080 # 或透過 Node.js npx serve npx serve . # 開啟瀏覽器訪問 http://localhost:8080
